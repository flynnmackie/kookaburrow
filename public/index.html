Monitor

Every monitored host is pinged and has its WinRM or SSH port checked. Green is up, red is not responding.

Monitor log

Every ping and remote port check, newest first: the command that ran, the host, when, and whether it worked or why not. The log is written to a file on the server (data/monitor-log.jsonl, trimmed at 20 MB), so it survives restarts; this page shows the latest 1000 checks.

Quarantine log

Every time a host was quarantined or released from Health > Monitor, newest first: who did it, when, and what happened. Each step also appears under Burrow > Respond.
