Trusting the CA on another machine

  • Windows: certutil -addstore -f Root kookaburrow-ca.pem (administrator)
  • Linux: copy to /usr/local/share/ca-certificates/kookaburrow-ca.crt, run sudo update-ca-certificates
  • macOS: Keychain Access, set to Always Trust
  • Firefox: Settings, Certificates, Authorities, Import
