## Kookaburrow 1.0.1

A patch release. It fixes a firewall leftover on uninstall, adds a Linux package, and brings in everything built since 1.0.

### Fixed
- **Uninstall left a Windows Firewall rule behind.** The 1.0 installer created `Kookaburrow web interface (TCP <port>)` but the uninstall only deleted a rule with the exact name `Kookaburrow web interface`, so the rule (and its open port) stayed after removal. Uninstall now removes every rule starting with that name, including the ones 1.0 created. This applies to both the `.msi` and the setup `.exe`.
- **UI size on large screens.** The interface was fixed at 75% zoom, so it looked small on big monitors. It now keeps 75% up to about 1920x1080 and scales up above that (capped at twice that size).
- **Windows installer left out the built-in YARA rule files** (`yara-rules/`), so the YARA picker had no built-in rules on an installed server. They are now included.
- **Large transfers from a Linux server** now check for `smbclient` and say how to install it when it is missing (Settings > External > Dependencies).
- **Running behind a reverse proxy**: set `KB_ALLOWED_HOSTS` to the names the proxy uses, otherwise the host check refused them.

### Added
- **Linux package (`kookaburrow_1.0.1_amd64.deb`)** for Debian and Ubuntu. It installs to `/opt/kookaburrow`, keeps data in `/var/lib/kookaburrow`, runs as the `kookaburrow` user under systemd, and depends on `nodejs` (20 or later), `python3`, `python3-venv` and `smbclient`. The WinRM engine is built on first install (needs internet once). First sign-in is `admin` / `admin`; change it. Settings overrides go in `/etc/kookaburrow/kookaburrow.env`.
- **Interface:** larger headings and side menus, side menus open by default, a clearer User Management page (separate blocks for users, roles and permissions, role toggles as pills), blue section headers, and much less explanatory text on every page.
- **Since 1.0:** workflows and processors (Hayabusa, Chainsaw, Zircolite, Eric Zimmerman tools, Volatility 3, Zeek), single sign-on (OIDC), Windows Firewall management, Kibana dashboards, recurring diffs and baselines, YARA rules, approvals, continuous watches, diff and drift reports, and about 200 more hunts.

### Notes
- Windows: run the `.msi` or the setup `.exe` (same installer). Upgrading keeps existing data in `C:\ProgramData\Kookaburrow`.
- Not yet tested on a real Linux server beyond a clean Debian 13 install; RPM packages are not provided yet.
